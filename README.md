# Грибница

Браузерный кликер-идл про выращивание грибов. Собирайте споры, расширяйте мицелий по карте, переживайте смену сезонов и превращайте один мухомор в грибной континент.

Игра целиком лежит в одном HTML-файле: без сборки, без зависимостей, без сервера.

## Как играть

1. Кликайте по мухомору, чтобы собирать споры.
2. Покупайте хозяйство: оно приносит споры само, даже когда вы не кликаете.
3. Тяните мицелий по карте к ресурсам, чтобы усилить своё хозяйство.
4. Следите за сезоном: от него зависит, сколько спор вы получаете и можно ли расти.

Прогресс сохраняется автоматически. Если закрыть вкладку, грибница продолжит работать: при возвращении вы получите половину накопленного за время отсутствия (но не больше, чем за 8 часов).

## Особенности

### Карта мицелия

Сетка 7×6 с землёй, влагой, брёвнами, подстилкой, елями, корнями и непроходимыми камнями. Мицелий растёт только в соседние клетки, поэтому путь к нужным ресурсам приходится планировать.

| Клетка | Что даёт |
| --- | --- |
| Земля | +2% ко всему хозяйству (это даёт любая заселённая клетка) |
| Влага | +20% гифам, мицелию и плодовым телам |
| Бревно | +30% гниющему бревну |
| Подстилка | +30% лесной подстилке |
| Ель | +30% старому лесу |
| Корни | +30% микоризной сети |
| Камень | Заселить нельзя, нужно обходить |

Цена новой клетки растёт с размером сети. Клетки с ресурсами стоят дороже обычной земли.

### Сезоны

Каждый сезон длится 2 минуты, полный год занимает 8 минут. Сезоны идут и пока вас нет в игре.

| Сезон | Эффект |
| --- | --- |
| Весна | Новые клетки карты на 40% дешевле |
| Лето | Производство спор +15% |
| Осень | Производство и клики ×2 |
| Зима | Производство ×0,4, гифы спят и карта не растёт |

Копите споры к весне, расширяйтесь, а к осени держите хозяйство наготове.

### Хозяйство

Восемь ступеней, от тонких гиф до «грибного континента»:

1. Гифы
2. Мицелий
3. Плодовые тела
4. Гниющее бревно
5. Лесная подстилка
6. Старый лес
7. Микоризная сеть
8. Грибной континент

Каждая следующая покупка одной ступени дороже предыдущей на 15%. Можно покупать по одной штуке, по десять или максимум на все споры.

### Улучшения

- Клик собирает вдвое больше спор (три улучшения).
- «Отклик мицелия»: каждый клик добавляет 2% от производства в секунду.
- Общие бонусы ко всему хозяйству: +25%, +50% и ×2.
- Для каждой ступени хозяйства есть удвоение производства при 5, 25 и 50 штуках.

### Золотая спора

Раз в 45–110 секунд на поляне ненадолго появляется золотая спора. Нажмите на неё, пока она не исчезла: вы получите либо крупную порцию спор сразу, либо «грибной дождь» с производством ×7 на 30 секунд.

## Запуск

Откройте файл игры в браузере двойным щелчком. Чтобы выложить игру на GitHub Pages, переименуйте файл в `index.html`, залейте в репозиторий и включите Pages в настройках (Settings → Pages).

Шрифты (Alegreya, Alegreya Sans, IBM Plex Mono) подгружаются с Google Fonts. Без интернета игра работает на запасных системных шрифтах.

## Технологии

- Чистые HTML, CSS и JavaScript, без фреймворков и сборки.
- Графика нарисована на SVG и CSS, картинок в проекте нет.
- Сохранение в `localStorage`: автосохранение каждые 10 секунд и при закрытии вкладки.
- Интерфейс подстроен под телефон и учитывает настройку «уменьшить анимацию».

## Планы

- Плесень-конкурент, которая заражает клетки карты.
- Престиж «споруляция» с выбором мутаций.
- Достижения и звук.
